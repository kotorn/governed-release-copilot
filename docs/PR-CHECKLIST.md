# PR Checklist

Use this checklist for the private ADO PR and for any final source review.

- [ ] Baseline export was captured before implementation.
- [ ] Feature contract is committed and readable.
- [ ] `ReleaseChangeV1` contract matches the validator.
- [ ] State model matches the SharePoint mapping.
- [ ] Static checks passed without inventing production data.
- [ ] Privacy scan and gitleaks passed.
- [ ] UI changes were exported, unpacked, and reviewed.
- [ ] Duplicate detection happens before the AI bridge.
- [ ] `NeedsInput` fails closed.
- [ ] Human approval precedes publication.
- [ ] Approved notes exist only after approval.
- [ ] DOCX exists only in the approved path.
- [ ] Approved-note citation was verified in a fresh conversation.
- [ ] Work IQ integration evidence is present.
- [ ] Feature-evidence matrix maps to the demo timestamps.
- [ ] Recovery commits and hashes are reconciled in the private ledger.
